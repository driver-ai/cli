# Driver CLI

Releases of `driver`, the Driver command-line interface: set up and use Driver from
the terminal.

## Install

macOS and Linux:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/driver-ai/cli/releases/latest/download/driver-installer.sh | sh
```

Windows: run the same command in WSL.

Then sign in with `driver auth login`, and run `driver status` to see what is set up
and what to do next.

Each release lists its changes and every download, with SHA-256 checksums, on the
[releases page](https://github.com/driver-ai/cli/releases).
